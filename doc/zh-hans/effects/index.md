# 效果概览

`bevy_alight_motion` 实现了多种 Alight Motion 效果，涵盖了从基础变换到复杂的 GPU 加速着色器。

## 功能分类

### [基础功能](./transform)
几乎适用于所有图层的核心动画属性。
- **变换与移动**：位置、旋转、缩放和锚点 (Pivot)。
- **形状与填充**：基于 SDF 的矩形和圆形渲染。
- **编组与分辨率**：嵌套场景与裁剪。
- **缓动曲线**：线性、步进和三次贝塞尔插值。

### [高级效果](./wipe)
通过自定义着色器实现的专项视觉修改。
- **擦拭 (Wipe)**：线性过渡与裁剪。
- **高斯模糊 (Gaussian Blur)**：高效的多 pass 模糊。
- **拉伸片段 (Stretch Segment)**：沿轴的 UV 变形。
- **调色板映射 (Palette Map)**：灰度到颜色的映射。
- **颜色替换 (Replace Color)**：针对性的颜色替换。
- **缩放辅助 (Scale Assist)**：自动尺寸调整。

### [遮罩](./masking)
使用图层形状控制可见性。
- **图层遮罩**：包含和排除遮罩。
