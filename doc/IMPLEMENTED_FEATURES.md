# bevy_alight_motion 已实现功能文档

本文档详细说明 `bevy_alight_motion` 目前已实现的 Alight Motion (AM) 功能。

## 项目概述

`bevy_alight_motion` 是一个 Bevy 插件，用于加载和播放 Alight Motion 项目文件 (`.amproj`)。它解析 AM 的 XML 结构，并在 Bevy 引擎中重现动画效果。

### 坐标系统转换

- **AM**: 原点在左上角，Y 轴向下增加
- **Bevy**: 原点在中心，Y 轴向上增加

转换公式：
```rust
bx = am_x - canvas_width / 2.0
by = canvas_height / 2.0 - am_y
```

### Transform2 效果

在基础变换之上添加额外的位置偏移，支持关键帧动画。

### Wipe2 效果

实现渐进式显示/隐藏动画：
- `start` / `end`: 可见范围 (0.0-1.0)
- `angle`: 擦除方向角度
- `feather`: 边缘柔和度

### 拉伸片段效果

UV 域变形效果，沿分割线拉伸图像：

**拉伸公式：**
```
stretch_factor = 1.0 + stretch_px / 50.0
new_width = orig_width * stretch_factor
```

例如：`stretch=50` 时宽度变为 2 倍。

## 架构说明

### 渲染方式

| 情况 | 渲染方式 |
|-----|---------|
| 颜色填充 + 无描边 | Bevy Sprite |
| 颜色填充 + 有描边 | SDF (bevy_smud) |
| 圆形 (任何填充) | SDF (bevy_smud) |
| 媒体填充 | MaskedSpriteMaterial |
| 媒体填充 + 效果 | StretchSegmentMaterial |

### 效果叠加策略

> **注意**：AM 允许任意效果叠加。当前实现使用自定义材质，未来可能需要多 pass 渲染或渲染到纹理以支持复杂效果组合。
